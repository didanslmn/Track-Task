# Stakeholder and Roles

## Project Roles

Pada proyek portfolio ini, satu orang dapat menjalankan beberapa role. Namun dokumentasi tetap dibuat seolah-olah proyek berjalan dalam tim profesional.

## Product Manager

### Responsibilities

- Menentukan problem statement
- Menentukan target user
- Menentukan MVP scope
- Menentukan prioritas fitur
- Menulis product brief dan PRD
- Menentukan acceptance criteria
- Menjaga agar scope tidak melebar

### Deliverables

- Product brief
- PRD
- Roadmap
- User stories
- Acceptance criteria

## Project Manager

### Responsibilities

- Membuat timeline
- Membuat sprint plan
- Memantau progress task
- Mengelola risiko
- Menjaga delivery sesuai scope
- Menyiapkan release checklist

### Deliverables

- Sprint plan
- Risk log
- Project status report
- Release checklist

## System Analyst

### Responsibilities

- Menganalisis requirement
- Membuat use case
- Membuat business rules
- Membuat data model
- Membuat API contract awal
- Menjelaskan edge case dan validation rule

### Deliverables

- Business requirements
- Use cases
- ERD/database design
- API specification
- Authorization rules

## Backend Developer

### Responsibilities

- Mengimplementasikan API
- Membuat database migration
- Membuat business logic
- Membuat authentication dan authorization
- Membuat automated test
- Membuat Docker setup
- Menyiapkan deployment

### Deliverables

- Backend source code
- Migration files
- Automated tests
- API documentation
- Dockerfile
- CI workflow
- Deployed API

## Role Mapping Untuk Portfolio

| Fase | Role Utama | Output |
| --- | --- | --- |
| Planning | Product/Project Manager | Product brief, PRD, roadmap, sprint plan |
| Analysis | System Analyst | Use case, ERD, API spec, authorization rules |
| Development | Backend Developer | Code, migration, tests, docs |
| Release | Project Manager + Backend Developer | Deployment, release notes, status report |
